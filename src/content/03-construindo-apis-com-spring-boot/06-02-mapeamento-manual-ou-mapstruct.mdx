## O problema

<Draft title="Por que importa (do currículo)">
O mapeamento manual cresce rápido e esconde bugs. O MapStruct gera código verificado em compilação, sem reflexão.

Comece com o problema que o conceito resolve e uma analogia do mundo real.
</Draft>

## O conceito

<Draft title="Tópicos previstos">
- Mapeamento manual com métodos estáticos (`ProdutoResponse.de(produto)`)
- MapStruct 1.6.3:
  - configuração com o processador de anotações
  - `componentModel = "spring"`
  - `@Mapping`
  - `unmappedTargetPolicy = ERROR`
  - mapeamento de records
  - `@MappingTarget` para atualização
  - *mappers* compostos
- Quando não usar MapStruct (poucos DTOs)
- Lombok: por que esta doc não usa (records cobrem quase tudo)
</Draft>
