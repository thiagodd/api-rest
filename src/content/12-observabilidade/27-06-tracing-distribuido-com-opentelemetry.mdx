## O problema

<Draft title="Por que importa (do currículo)">
Com várias dependências (PagaFácil, FreteJá, banco, Redis), só o *tracing* mostra onde o tempo de uma requisição lenta foi gasto.

Comece com o problema que o conceito resolve e uma analogia do mundo real.
</Draft>

## O conceito

<Draft title="Tópicos previstos">
- *Spans*, *traces*, contexto; W3C Trace Context (`traceparent`)
- `spring-boot-starter-opentelemetry` (Boot 4) × Micrometer Tracing com *bridge* OTel × agente Java do OpenTelemetry: quando usar cada um
- Exportação OTLP; amostragem (*sampler*)
- Propagação automática no `RestClient` e no `@Async`
- *Spans* customizados
- *Exemplars* (de uma métrica para o *trace*)
- OpenTelemetry Collector
</Draft>
