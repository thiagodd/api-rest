## O problema

<Draft title="Por que importa (do currículo)">
Exportar 1 milhão de linhas carregando tudo em memória causa `OutOfMemoryError`. O *streaming* resolve.

Comece com o problema que o conceito resolve e uma analogia do mundo real.
</Draft>

## O conceito

<Draft title="Tópicos previstos">
- `Resource` / `InputStreamResource`
- `Content-Disposition` (RFC 6266; `attachment`, `filename*` UTF-8)
- `StreamingResponseBody`
- *Streaming* do banco (`Stream<T>` do Spring Data com `@Transactional(readOnly)`, *fetch size*)
- Range requests → 206 Partial Content, `Accept-Ranges`; *timeouts* assíncronos
- NDJSON para *streaming* de JSON
</Draft>
